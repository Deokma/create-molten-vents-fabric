# Create: Molten Vents (Fabric 1.20.1)

![Mod Logo](https://raw.githubusercontent.com/Deokma/create-molten-vents-fabric/1.20.1/src/main/resources/assets/molten_vents/textures/icon.png)

## 📜 Description
This is an **unofficial port** of the mod [Create: Molten Vents](https://modrinth.com/mod/create-molten-vents) for **Fabric 1.20.1**. The original mod was developed by [Apothicon02](https://github.com/Apothicon02/Create-Molten-Vents), but this port does not include the structure generation from the original mod.

## 🔥 Features
- Adds **Volcanic Ventures** from which molten resources can be obtained.
- Realizes interaction with **Create** mechanics.
- Allows you to get molten versions of various stone blocks.

## ❗ Differences from the original
- **Removed structure generation** (volcanic vents do not appear in the world, they must be placed manually).
- Full compatibility with **Fabric API** and **Create Fabric**.

## 📦 Installation
#### Required Mods:
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Create (Fabric)](https://modrinth.com/mod/create-fabric)

## ⚙ Development
### Build Project
``sh
./gradlew build
```

### Start in the development environment
```sh
./gradlew runClient
```
