# Create: Molten Vents (Fabric 1.20.1)

![Mod Logo](https://raw.githubusercontent.com/Deokma/create-molten-vents-fabric/refs/heads/1.20.1/src/main/resources/assets/molten_vents/icon.png)

## 📜 Description
This is a **Fabric 1.20.1 port** of the mod [Create: Molten Vents](https://modrinth.com/mod/create-molten-vents). The original mod was developed by [Apothicon02](https://github.com/Apothicon02/Create-Molten-Vents), and this port is made with permission from the original author.

## 🔥 Features
- Adds **Volcanic Ventures** from which molten resources can be obtained.
- Realizes interaction with **Create** mechanics.
- Allows you to get molten versions of various stone blocks.

## 📦 Installation
#### Required Mods:
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Create (Fabric)](https://modrinth.com/mod/create-fabric)

## ⚙ Development
### Build Project

```sh
./gradlew build
```

### Start in the development environment

```sh
./gradlew runClient
```
